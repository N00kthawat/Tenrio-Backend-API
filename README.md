# Tenrio Backend API

Initial NestJS-based backend API skeleton for Tenrio.

## Requirements

- Node.js 22+
- npm 11+

## Run

```bash
npm install
npm run start:dev
```

The API starts on `http://localhost:3000`.

## Endpoints

- `GET /v1/health`
- Swagger docs: `GET /v1/docs`

## Quality Checks

```bash
npm run lint
npm run typecheck
npm test
```
